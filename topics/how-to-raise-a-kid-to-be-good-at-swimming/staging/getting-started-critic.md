# Critic Report — Getting Started with Swimming — 2026-04-09

## Overall Assessment

A solid guide that covers the core RO1 territory competently. The readiness checklist is genuinely useful and the program-type breakdown is well-structured. The main weakness is that the "How do I choose a good swim school or instructor for a beginner?" must-answer item is almost entirely unaddressed — the article tells parents what program types exist but gives them no evaluation criteria for choosing between specific providers.

## Must-Fix Before wiki/ Graduation

1. **Missing "Common Mistakes" section — D3 = 0, blocks graduation.** This is a guide article; the "Common Mistakes" section is mandatory. The compiler must add a section with specific, non-generic mistakes. Examples of appropriate mistakes to include: (a) Choosing a swim school based on proximity alone without evaluating instructor-to-child ratios; (b) Moving a child to a bridge program before they can independently complete a single 25-yard length, causing repeated frustration and instructor friction; (c) Treating "Level 4" completion at one program as equivalent to "Level 4" at another — levels are not standardized across providers.

2. **RO1 must-answer "How do I choose a good swim school or instructor for a beginner?" is not answered.** The article lists program categories (YMCA, private school, LTS, etc.) but provides zero evaluation criteria. A parent reading this cannot tell a good beginner program from a poor one. The compiler must add a sub-section — even brief — covering: instructor-to-child ratio (the AAP recommends lower ratios for safety), whether the program uses USA Swimming or American Red Cross curricula, and 2-3 observable green/red flags applicable at the beginner level (e.g., instructors who stay dry on deck vs. those in the water with young children).

## Should-Fix

1. **Program-type section describes without deciding.** The section "Program Types Explained" lists five program types but gives no guidance on which is appropriate when. A parent of a 6-year-old beginner, a 9-year-old intermediate, and a 7-year-old who can already swim independently all read the same section and get nothing decision-specific. Add a brief "Which program type is right for my child?" mapping grid (age + skill level → recommended entry point).

2. **The UC Berkeley Pre-Team example is too detailed for a guide article.** The three-sentence description of UC Berkeley's specific entry requirements (snorkel, fins, three-level structure) reads like an entity profile excerpt dropped into a guide. It should be condensed to one sentence and wikilinked if a UC Berkeley entity article exists, or cut to just "contact the program for specific entry requirements."

## Graduation Decision: NEEDS-REVISION

Return to wiki-compiler-agent with this report. Two must-fix items: add a "Common Mistakes" section with specific mistakes (not generic advice), and add beginner program evaluation criteria to address RO1 must-answer item 3.
