# Critic Report — Recommended Books and Resources by Level — 2026-04-10

## Overall Assessment

This reference guide serves RO4's "what books should my child use at each level" must_answer item completely. It is organized by level, includes prices, names specific titles and authors, and provides a comprehensive free resources table. The article is primarily a reference list, not a decision guide, which appropriately limits its action-framing. The main gap is the absence of a Common Mistakes section and the absence of any guidance on how to select within a stage when multiple books target the same level.

## Must-Fix Before wiki/ Graduation

1. **No "start with" recommendation within each stage.** Stage 3 (Intermediate Level) lists six books all targeting "AMC 12/AIME." A parent or student at this level cannot tell which to begin with. The article needs a "Recommended starting point:" line per stage — e.g., "Stage 3: Start with Intermediate Algebra (AoPS), then add Intermediate Counting & Probability. Zeitz and Engel are supplementary once core AoPS series is complete." Without this, the article answers "what books exist" but not "what books should I use," which is what RO4 asks. This is a meaningful actionability gap that blocks the article's stated purpose.

## Should-Fix

1. **Physics book section creates dual-maintenance with `physics-competitions-pathway.md`.** The physics pathway article currently has its own "Book Progression for Physics Competitions" section. The critic report for that article flags this as a must-fix scope violation, recommending the physics pathway article defer to this guide. If that fix is applied, this guide becomes the canonical physics book source — confirm the two lists are reconciled and identical before graduating either article.

2. **Stage 4 (Olympiad) lacks structure for newcomers.** The olympiad section lists ~12 books organized by topic (Geometry, Algebra, Number Theory, Combinatorics, General) but does not say where to start. A student passing AIME for the first time faces an intimidating list. A one-sentence entry point per topic — e.g., "For geometry, start with EGMO (Evan Chen) before Geometry Revisited" — would make this stage actionable rather than encyclopedic.

3. **The "Competition Math for Middle School (Batterson)" entry in Stage 2 has no notes field** unlike every other row. Adding a brief note — "MATHCOUNTS-focused; bridges Beast Academy to AoPS Introduction series" — would maintain consistency.

## Graduation Decision: NEEDS-REVISION

The absence of "start with" recommendations within each stage means the article tells parents what books exist but not what to use, which fails the RO4 must_answer item at the action level. This is a must-fix that blocks graduation.
