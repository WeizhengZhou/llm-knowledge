# San Francisco Day School Kindergarten Admissions Guide

## Application Platform & Fees
Applicants use **Ravenna**, an online admission portal where families create accounts and track application status. There is a $100 fee per application, though fee waivers are available upon request to admission@sfday.org.

## Eligibility Requirement
Children must "turn 5 by August 1, 2026" to apply for the Class of 2035.

## Key Timeline

| Date | Event |
|------|-------|
| September 2 | Portal opens |
| September 18 | Kindergarten Open House (6:00-8:00 p.m.) |
| Sept-December | School tours available |
| October 29 | Adjusted Tuition Q&A Webinar |
| December 19 | Application deadline |
| October-March | Parent interviews (scheduled via Ravenna) |
| January | Student assessment and parent presentation |
| January 12 | Financial aid application due (Clarity platform) |
| March 19, 12:00 p.m. | Admission decisions released |
| March 24, 10:00 a.m. | Enrollment contracts and deposits due |

## Required Submissions

**Application Materials:**
- Completed application questionnaire with "four carefully considered questions" about the child
- ISSFBA Evaluation Form completed by child's teacher(s)

**Assessment Components:**
Families must attend an on-campus parent/guardian interview and a student assessment/presentation session where "our committee to get to know the students."

**Financial Aid:**
Submit applications through the Clarity platform by January 12.

## Application Process Overview
The school reviews submitted materials before scheduling interviews, emphasizing this is an opportunity "for us to get to know you" and your child's learning style and interests.

## Notes
- Age cutoff: must turn 5 by August 1 (earlier than California public school September 1 cutoff)
- Uses ISSFBA Evaluation Form (shared across ISSFBA member schools)
- Decisions coordinated citywide: released March 19
