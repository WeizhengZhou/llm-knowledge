# Helios School IQ Assessment Requirements

## Required Tests

Helios mandates the **Wechsler Intelligence Quotient (IQ) assessments**:
- **Under age 6:** Wechsler Preschool and Primary Scale of Intelligence (WPPSI-IV)
- **Age 6+:** Wechsler Intelligence Scale for Children (WISC-V)

## Score Requirements

"Helios does not have a minimum FSIQ requirement for applicants." The school evaluates the complete report, considering relative strengths across subtests rather than focusing solely on the Full Scale IQ score.

(Note: This is a key distinction from Nueva School, which explicitly targets FSIQ ~130+ at the 98th percentile.)

## Required Subtests

Both assessments must include:
- Verbal Comprehension Index
- Visual Spatial Index
- Fluid Reasoning Index
- Working Memory Index
- Processing Speed Index
- Full Scale IQ
- General Ability Index

## Logistics

- **Deadline:** February 2, 2026
- **Provider:** Any licensed professional experienced with Wechsler assessments
- **Submission:** PDF format (no password protection) via Ravenna platform or direct email to admissions@heliosschool.org
- **Timeline:** Schedule assessments "as soon as possible" to meet deadline

## Preparation Guidelines

Parents should avoid test-specific preparation, as "exposing your student to test content would invalidate the test results."

## Comparison Note

Unlike Nueva (which requires FSIQ ~130 and publishes a specific cutoff), Helios evaluates the full profile without a published minimum. Helios serves gifted students but uses holistic assessment across all subtest indices.
